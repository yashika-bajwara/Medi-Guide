# MediFind 🏥

## AI-Powered Hospital Finder

MediFind is a Django-based healthcare website that helps users find suitable hospitals based on their health problems, location, facilities, and emergency services.

It also includes an AI-powered chatbot for answering general healthcare-related questions.

## Features

- 🏥 Hospital search
- 🔎 Search by health problem/treatment
- 📍 Search by city
- 🚑 Emergency service information
- 🚨 Ambulance availability
- 🏢 Hospital facilities
- ⭐ Hospital ratings
- 📋 Detailed hospital information
- 🩺 Treatment and department information
- 🤖 AI-powered chatbot
- 📱 Responsive user interface
- 🖼️ Healthcare and hospital images
